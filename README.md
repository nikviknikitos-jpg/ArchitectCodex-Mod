# ArchitectCodexMod (Fabric 1.20.1) — Наследие Древнего Архитектора

Масштабный сюжетно-приключенческий мод: 9 конструктов-союзников, интерактивный Кодекс
Архитектора (GUI-книга), босс «Поврежденный Колосс», древние башни, 4 функциональных блока,
15+ предметов, полный сет брони с полетом.

## Команды
- `/givearchitect` — весь набор предметов.
- `/architectunlockall` — открыть все страницы Кодекса.

## Сборка
JDK 17, Gradle 8.8, workflow GitHub Actions прилагается.
